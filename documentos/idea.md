# Idea del proyecto

Sistema web para administrar productos y controlar las entradas y salidas de mercadería de un negocio de repuestos e insumos. El administrador inicia sesión, registra productos, consulta y busca el inventario, modifica datos, registra movimientos y revisa el historial. El sistema actualiza las existencias automáticamente y advierte cuando un producto llega al stock mínimo o queda por debajo.
