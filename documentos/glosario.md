# Glosario

- **Producto:** repuesto o insumo administrado por el sistema.
- **Stock:** cantidad de unidades disponibles.
- **Stock mínimo:** umbral configurado por el administrador para identificar existencias bajas.
- **Entrada:** movimiento que aumenta el stock.
- **Salida:** movimiento que disminuye el stock.
- **Movimiento:** registro histórico de una entrada o salida, con producto, tipo, cantidad y fecha.
- **Administrador:** usuario autorizado para utilizar el sistema.
- **API:** interfaz mediante la cual el frontend solicita operaciones al backend.
- **Autenticación:** verificación de las credenciales del administrador.
- **Hash:** representación irreversible usada para no guardar la contraseña original.
- **Migración:** script que crea o modifica la estructura de la base de datos.
- **Variable de entorno:** configuración externa al código, usada para guardar direcciones y secretos.
