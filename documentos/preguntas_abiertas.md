# Preguntas abiertas

1. ¿Se permitirá más de un usuario administrador en una versión futura? El alcance inicial contempla un administrador.
2. ¿Se necesitarán categorías, códigos SKU o proveedores? No están incluidos en el spec actual.
3. ¿Se necesitará exportar el inventario a Excel o PDF? No está incluido en el spec actual.
4. ¿Se necesita registrar quién realizó cada movimiento? La implementación registra el usuario administrador asociado.
5. ¿Se necesita editar o anular movimientos? No está definido en el spec actual; no se incorpora para evitar alterar el historial.

Estas preguntas no se convierten en funcionalidades hasta que se actualice el spec.
